# Org parser and backend measurements, 2026-11-17

Corpus: 35 files, 32,336 lines, 1.11 MB (Org manual, Org guide, org-mode/testing/examples, nvim-orgmode fixtures, synthetic-agenda.org with 600 headings in Davy's kittymax style). Reference: Org's own parser, org-element (Org 9.7, Emacs 31.1), via el-sum.el.

Real misparses found by reduction:
- orgize 0.9: `SCHEDULED: <2026-11-22 Mon .+1d>` (a habit repeater) is not read as planning, so the property drawer under it is lost. Habits are used daily in kittymax. Disqualifying.
- orgize 0.10-alpha: a table preceded by `#+NAME:` or `#+CAPTION:` is not parsed as a table. Named tables are babel inputs.
- tree-sitter-org: tables 197 vs 143, lists 630 vs 802, 69 ERROR nodes. Not reduced further.
