### Blocking findings

#### 1. The start screen stays over a file opened from it

`shown()` (dash.c:140) closes the dashboard when the window shows another buffer, the buffer changed, a second window opened or insert mode started. But `core_edit_file` reuses the empty start buffer (core.c:663, Neovim's `buflist_new()`), so after Recent Files, Find File or Find Text opens a file, `e->buf` is the same pointer, `undo_seq` is the same and the mode is normal. The dashboard keeps covering the file, and `f n g r q j k Enter` stay the dashboard's keys: `q` quits the editor, `r` opens the picker instead of replacing a character.

Reproduced four ways (**measured**):
- terminal: `python3 drive.py 80x24 'r|\r'` shows the dashboard with `"…/b.txt" 1L, 6B` on the last line; adding `|q` exits (2 runs);
- as a test: `pr-61-repro/stale.c` prints `file text shown: 0, dashboard shown: 1` and fails at `CHECK(!tools_key(&e, 'q'))`;
- Windows build under Wine: `wine-stale.png`;
- no data can be lost by it (any edit closes the dashboard), but the main path of the screen, picking a file, ends on a screen that hides the file.

No check sees it: `test_tools_dash` only changes the buffer with `core_edit`. Wanted: the fix (the buffer having a path is enough to tell), a test that opens a file through `core_edit_file` over the dashboard, and a plant for it.

#### 3. The Windows half of the picker has no check

The PR says "Everything works on Windows too". For `src/shada/` that is measured (`test_shada_win` under Wine, 2 plants). For `pick.c` it is not: `absolute()`, `sep()`, the drive-letter and `\\server` rule and `fr_visit`'s Windows branch have no test and no plant; `make wincc` only compiles them. I saw the recent picker list and open one file under Wine (1 run), which is all the evidence there is. CLAUDE.md asks that things are run and that every check has a plant.

Also `pick.c:212` still tests `P.a[i->file + P.cwdlen] == '/'` where `same()` and `path_rel()` now use `sep()`, so on Windows a file under the cwd named with `\` misses the cwd bonus (**hypothesis**, read not run).

Wanted: a Wine test for the path rules with plants, or the Windows picker code left out of this PR until it has one.

### Other findings (not blocking)

#### 4. The Wayland window loses the left stroke of the cat's ears (not this PR's code)

In the window, `/\` after a space is drawn as `\` alone (`wayland-picture.png`). The same happens in an ordinary file on the stand-in (`lig.txt`, `wayland-ligature-file.png`: `x /\ y` shows `x  \ y`, while `a/\b` and `│/\│` are whole), so it is a ligature fault in the font or Wayland code on main, not in dash.c. **measured**, 1 run each, JetBrains Mono. It spoils the first thing Davy sees on Linux, so it should be fixed by its owner before or with this PR. The terminal and the Windows build draw the ears whole.

#### 5. Small windows

Below 14 rows the lower keys are off the screen and the cursor moves onto rows that do not exist: at 30x10 after four `j` the cursor is on the command line and Quit is not visible (`drive.py 30x10 'j|j|j|j'`). snacks scrolls its buffer there; the oracle's cases only record the first item. No backend indexes the grid by the cursor, so nothing crashes (wl.c and backend.c compare, tty.c sends the position). **measured**, 1 run.

Under Wine the default window is 80 columns by 27 rows, which is below the picture's rule (47 by 31), so the Windows build shows no cat and frog until the window is enlarged (`wine-start.png`). Whether real Windows opens a taller default window was not measured.

#### 6. Two editors quitting at once: now measured

The PR tags this a hypothesis. `race.py`, two editors on different files, each round from a seeded store: with the two `:q` sent together, one editor's file was missing from `oldfiles` in 50 of 50 rounds; with 5 ms, 50 ms and 500 ms between them both were kept in 30 of 30. The file was well-formed and no temp or kept file was left in all 80 rounds. So "never corrupted" holds as measured, and "one may lose the other's files" happens every time the exits coincide. Neovim's behaviour in that race was not measured.
