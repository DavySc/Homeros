# RAD Debugger trace probe

Not part of Homeros's code. This branch has no shared history with `main` on purpose, so the
Homeros checks do not run on it. It builds the RAD Debugger (MIT, EpicGamesExt/raddebugger) at the
commit the knowledge base is pinned to, on a GitHub Windows runner, and records what it does.
Davy approved the runner on 2026-11-18; nothing from any personal machine is involved.
