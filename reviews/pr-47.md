1. **Org is not in `WIN_SRCS`.** It is built from `$(BASE)`, but `src/org/` is in `MODULES`, not `BASE`, so it is linked into the editor yet wincc never compiles it for Windows. It compiles today (**measured**). Building `WIN_SRCS` from `$(filter-out tty font tools wl,$(MODULES))` covers org and any later package without another edit.
2. **`$(CPPFLAGS)` brings Linux build flags into the Windows compile**: `-I/usr/include/glib-2.0`, `-I/usr/lib/x86_64-linux-gnu/glib-2.0/include` (FreeType's and HarfBuzz's pkg-config) and `-DHOMEROS_WL -Ibuild/wl`. Harmless now: no wincc file includes those headers, and main.c tests `_WIN32` before `HOMEROS_WL` (**hypothesis** that nothing else depends on it; only main.c names HOMEROS_WL outside src/wl). Passing only tree-sitter's `-I` would say what the Windows build really reads.
