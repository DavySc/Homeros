## Findings

**B1 (blocking, fixed in 5e8d5fb).** `homeros.desktop` had `Exec=homeros %F`, but `main.c` takes exactly one FILE. Measured: `./homeros a b` prints the usage line and exits 2 (1 run), so opening two files from a file manager showed nothing. Now `Exec=homeros %f`: the launcher starts one instance per file (Desktop Entry spec). `desktop-file-validate` clean on both versions.

**N1 (non-blocking, for the start screen thread).** A launch from the app menu passes no file: `./homeros` exits 2 with no window (measured, 1 run). The entry is right; the editor needs no-argument launch, which the start screen thread brings.

**N2 (non-blocking, thread 0).** `assets/` is a new top-level directory not in CLAUDE.md's layout table. Owner: thread 0 (it holds the Makefile's `install` and `wincc` lines that use it).

**N3 (note).** All 8 .ico frames are PNG-compressed 32-bit. Windows loads PNG frames at every size since Vista; measured below under Wine. Only pre-Vista loaders need BMP frames, which Davy does not run.
