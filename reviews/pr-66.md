## What `make dupes` catches, and what it does not

`reviews/pr-66-repro/dupes-probes.sh` (run from the repo root) plants ten
copies and reports what the check says.

| Probe | Result |
|---|---|
| a function body copied verbatim into another file | caught |
| the same copy reformatted, with comments added | caught |
| a copy in a `static inline` function in a header | caught |
| a third copy of a pair already in the known list | caught |
| a copy after a `"/*"` string literal | not caught at a9399bc; caught at 936e755 |
| a copy with one identifier renamed | not caught |
| a copy under `tests/` | not caught |
| a copy inside a macro body | not caught |
| a line added by hand to `tests/dupes-known.txt` | passes |
| a listed copy that grows longer | passes |

The last five are limits of the method, not bugs: the check compares token
text inside function bodies under `src/`, `ref/` and `include/`. CLAUDE.md now
says so, so a review still has to look for renamed copies. The known list
shrinking is kept by review (a diff that adds a line to it is visible) and by
the stale-entry failure, which has a plant.

`make dupes` takes 0.9 s.

## Findings of the first pass (a9399bc), both fixed

**B1. The PR failed its own check once merged with main.** With PR 26 on main
(d4646c4), `make dupes` reported three copies in `src/keys/` and one stale
line for `ref/keys.c`, and the stale-entry plant no longer applied. Fixed at

**B2. `make index` left out 147 of 872 function definitions**, every one whose
body is on the line of its signature. A builder who greps the index for an

definitions at 936e755 and 1,118 on the merge with main 516332c.

Smaller points, all taken: string literals are skipped before comment
markers; `grid_puts` computes each cluster's length once; DESIGN.md's rule
line names the exception; the T-SQL row's figures carry their tags.

## The folds

`loop_now`, `file_same`, `src/loop/timer.c` and the cell helpers are the old
code moved, read side by side with what they replace.

`grid_puts` replaces three loops that were not the same. `puts_diff.c` runs
the old picker loop, the old command-line loop and the new function on
100,000 random strings per class and compares the grids:

| Input | Picker: grids that differ | Command line: grids that differ |
|---|---|---|
| ASCII | 0 | 0 |
| narrow non-ASCII | 0 | 0 |
| wide, emoji, combining | 0 | 3 |
| control characters | 0 | 90,226 |
| invalid UTF-8, C1, unprintable | 91,402 | 87,455 |

The differences are the new function being more right: the old command line
wrote raw control bytes into cells and drew narrow characters after a wide one
that did not fit; the old picker gave an invalid byte one blank where the text
view gives it the width of its `<xx>` form. No input reads or writes out of
bounds under ASan and UBSan. The `face` parameter is used by PR 59.

## The engine thread

DESIGN.md's "The one exception" and CLAUDE.md's rule carry the six rules of
`raddbg-kb/09-homeros-fit.md` ("The engine thread (decided)") without loss:
one thread only while debugging; no shared writable memory, two queues; wakes
through the existing event source; no calls across, enforced by a check with a
plant; the engine owns what it touches; the queues modelled in TLA+ first and
tests under ThreadSanitizer. `design/CLAUDE.md` (the seed copy, already
different from the root file) still says "No threads".
