## What the PR does

`make_font()` in `src/win/backend.c` passes `ANTIALIASED_QUALITY` instead of
`CLEARTYPE_QUALITY` to `CreateFontW`, because ClearType's coloured fringes made
text look blue on Davy's dark background (`syntax/cleartype-zoom.png` in the
project files). The plants file says why no plant can see this under Wine.

## Every path that sets font quality or draws text

Read, at the PR head (`git grep` over `src/`, `include/`, `ref/`, `tests/`):

- One font is ever created: `make_font()` (backend.c:63). No `LOGFONT`,
  `CreateFontIndirect`, `DrawText`, `TextOut`, Uniscribe, DirectWrite or
  `SystemParametersInfo` font-smoothing call exists anywhere.
- Text is drawn by two `ExtTextOutW` calls (backend.c:92, a background-only

  selected into `mem`, which is only ever `font` (or the stock `SYSTEM_FONT`

- Font fallback: a missing glyph goes through GDI font linking inside
  `ExtTextOutW`; linked fonts are realised with the base font's quality
  (**hypothesis**, from GDI's documented behaviour; Wine cannot show it).

## Findings (none blocking)

1. **Greyscale obeys the font's `gasp` table, so a fallback face can turn
   aliased (jagged) at 100 % scaling.** 12 pt at 96 dpi is 16 px. JetBrains
   Mono's `gasp` asks for grey at every size (one range, 0xFFFF → flags 15,
   read from the .ttf), so it smooths. Liberation Mono's `gasp` turns grey off
   from 9 to 16 px, and Wine draws it bi-level at 16 px ("partial 0" above),
   smooth again at 20 px. Courier New, which Liberation Mono copies, has the
   same kind of table (**hypothesis**). If JetBrains Mono is not installed on
   Davy's laptop (the trial zip does not bundle it, and the glyphs in the
   screenshot could be Consolas), text could look jagged rather than blue at
   100 % scaling; at 125 % (20 px) or more it smooths. Not blocking: it only
   affects a fallback face, real ClearType never showed it, and package 7's
   own renderer replaces GDI text. Add to the README's real-Windows checks:
   "is text smooth (grey edges) or jagged at 100 % scaling?"
2. `tests/test_win.c:217` said "(ClearType)"; fixed in 1e9710e.
