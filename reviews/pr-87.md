## Notes (non-blocking)

1. **Residual, measured.** `dl_face` walks forward over any amount of white space to see whether a word is a relation (`while (is_space(...)) e++`). A Soufflé word followed by 1 MB of blank lines: a 50-line frame at the top costs a median 2.36 ms (range 2.29 to 2.47) against T-SQL's 1.25 ms (1.19 to 1.30) for the same text; 5 alternating process runs per side, each the median of 21 frames (`reviews/pr-87-repro/ws.c LANG GAP`). 10 MB: 25.7 ms against 13.2 ms (1 run). Only a pathological file reaches it; a bound (for example, stop at the next line) would change "a\n(b)" and is not worth it now.
2. **Hypothesis.** `product` is now a function word (SQL Server 2025's PRODUCT aggregate). It is a common column and table name, so `Product` columns turn function pink. Whether Davy's SSMS colours it the same way is not checked; worth one look in his next SSMS screenshot.
3. JSON's `true`/`false`/`null` are now matched case-sensitively (`copy(..., 0)`): `TRUE` in a .json file is plain. That is tree-sitter-json's behaviour (the literal "true"), so it is a fix, not a regression.
