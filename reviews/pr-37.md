## Findings

### 1. The test does not guard the neighbouring keys (fix before merge)

The PR took `ESC [ 3 ~` out of the test's list of sequences that must be dropped and put `ESC [ 3;5 ~` in. That left no single-digit `CSI n ~` in the list. A decoder that takes every `CSI n ~` for Delete (so Insert, PageUp and PageDown delete a character) passes the test.

- **measured**: plant "any CSI n tilde is Delete" (`extra-plants.txt`, `j == 3 && s[3] ==` in place of the PR's condition): `make test TESTS=tty_input` passed, 1 run.
- The other four plants of mine are caught (Ctrl-Delete taken for Delete, Delete as `x`, Delete as KEY_LEFT, Delete eating the next byte).

Fix (in 393f390): add `"\x1b[2~"` to the dropped list, and a plant for it. **measured**: with the fix the test passes and both plants are caught, 1 run each, also after merging main d49035e.

### 2. `j == 3 &&` is never needed (top rule)

`'3'` is not a final byte, so if `s[2] == '3'` the loop has gone past it and `j >= 3`; the function has already returned if `j == n`, so `s[3]` is inside the input; `'~'` is a final byte, so `s[3] == '~'` makes the loop stop there and `j == 3`. **proved** by that argument, and **measured**: the PR with and without `j == 3 &&` agree on all 3,897,432 calls of `keydiff.c`. The plant "the redundant test dropped" is, as it should be, not caught.

393f390 removes it and adjusts the PR's plant text.

### 3. Ctrl-Delete and Alt-Delete delete in Neovim (not for this PR; a known difference to record)

**measured** (`e2e.py`, 3 runs): in Neovim `CSI 3;5~` and `CSI 3;3~` act as `<Del>` in normal and insert mode. Shift-Delete does nothing in normal mode and types the text `<S-Del>` in insert mode. Homeros drops all three. The PR's reason ("keys.h has no key for it") holds for a separate key, but Neovim's behaviour needs none: Ctrl and Alt forms could give KEY_DEL. That is a choice about what Davy wants Ctrl-Delete to do, so it belongs in the keys package's list of differences or with Davy, not here.

### 4. Seen on the way, older than this PR

- Insert (`CSI 2~`), PageUp, PageDown, Home, End are still dropped; Neovim acts on them (**measured**, the "5~ 6~" case of `e2e.py`).
- A Delete that arrives slower than 50 ms per piece becomes Esc `[` `3` `~` in both editors. The saved files differ only because the reference keys have no `~` (toggle case) yet: typing `[3` and `~` by hand gives the same difference (**measured**, 3 runs).
- An Esc inside an unfinished CSI is read as a parameter byte, so `ESC [ 3` followed at once by `ESC [ 3 ~` gives `3` `~` (**measured**, `keys.c`). A terminal never sends that; a person would have to type Esc `[` `3` and press Delete inside 50 ms.
